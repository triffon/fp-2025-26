## 1. Функции от по-висок ред над списъци

Както вече знаем, функциите от по-висок ред са функции, които приемат други функции като аргументи или връщат функции като резултат. В Haskell има много полезни функции от по-висок ред за работа със списъци.

### 1.1 Познатите ни map, filter, foldl, foldr, any, all

```haskell
map (*2) [1, 2, 3, 4]           -- => [2, 4, 6, 8]
map toUpper "hello"             -- => "HELLO"
filter even [1, 2, 3, 4, 5, 6]  -- => [2, 4, 6]
foldr (-) 0 [1, 2, 3, 4]        -- => -2 == (1 - (2 - (3 - (4 - 0))))
foldl (-) 0 [1, 2, 3, 4]        -- => -10 == ((((0 - 1) - 2) - 3) - 4)
any (<3) [1, 2, 3, 4]           -- => True
all (<3) [1, 2, 3, 4]           -- => False
```

### 1.2 Някои други вградени функции - zipWith, takeWhile и dropWhile

- `zipWith` прилага функция върху съответните елементи на два списъка. Бележка - резултатният списък има същия брой елементи като по-краткия списък.
- `takeWhile` взима елементи докато условието е изпълнено. Спира при първо неуспешно изпълнено условие.
- `dropWhile` премахва елементи докато условието е изпълнено. Спира при първо успешно изпълнено условие.

```haskell
zipWith (+) [1, 2, 3] [4, 5, 6]  -- => [5, 7, 9]
zipWith max [1, 5, 3] [4, 2, 6]  -- => [4, 5, 6]
takeWhile (<3) [1, 2, 3, 4, 3, 2]  -- => [1, 2]
dropWhile (<3) [1, 2, 3, 4, 3, 2]  -- => [3, 4, 3, 2]
```

## 2. Анонимни функции (Lambda функции)

Анонимните функции (lambda функции) са функции без име, които се дефинират на място. В Haskell се дефинират с `\` (което прилича на гръцката буква λ).

### 2.1 Синтаксис

```haskell
\аргумент1 аргумент2 ... -> израз

-- Примери
(\x -> x * 2) 5                    -- => 10
(\x y -> x + y) 3 4                -- => 7
map (\x -> x * x) [1, 2, 3]        -- => [1, 4, 9]
filter (\x -> x > 5) [1, 3, 7, 9]  -- => [7, 9]
```

### 2.2 Pattern matching в lambda функции

```haskell
map (\(x, y) -> x + y) [(1, 2), (3, 4)]  -- => [3, 7]
filter (\(x, y) -> x < y) [(1, 2), (3, 1)]  -- => [(1, 2)]
```

**Забележка:** В lambda функции (`\x -> ...`) можете да използвате pattern matching, но **не можете** да използвате guards, `where` или `let` директно. За guards в lambda функции трябва да използвате например `if-then-else` израз:

```haskell
-- Guards в lambda НЕ работи директно, използвайте if-then-else
map (\x -> if x > 0 then x * 2 else 0) [-2, -1, 1, 2]
```

## 3. Странични ефекти и класът IO

В Haskell функциите са "чисти" - не могат да имат странични ефекти (като четене от клавиатура, писане на екран, четене/писане във файлове). За да работим със странични ефекти, използваме типа `IO a`, който представлява действие, което при изпълнение може да има странични ефекти и да върне стойност от тип `a`.

### 3.1 Основни IO операции

```haskell
-- Четене от стандартния вход
getLine :: IO String          -- Чете ред от конзолата
getChar :: IO Char            -- Чете един символ
getContents :: IO String      -- Чете всичко до EOF

-- Писане на стандартния изход
putStr :: String -> IO ()     -- Извежда низ без нов ред
putStrLn :: String -> IO ()   -- Извежда низ с нов ред
print :: Show a => a -> IO () -- Извежда стойност (използва show)

-- Примери
putStrLn "Hello"              -- Извежда "Hello\n"
print 42                      -- Извежда "42\n"
print [1, 2, 3]               -- Извежда "[1,2,3]\n"
```

### 3.2 Комбиниране на IO операции

IO операциите се комбинират с `>>` (последователност без предаване на стойност) и `>>=` (bind - последователност с предаване на стойност).

```haskell
-- >> - изпълнява две IO операции последователно
putStrLn "First" >> putStrLn "Second"

-- >>= - предава резултата от първата операция към втората
getLine >>= \line -> putStrLn ("You entered: " ++ line)
```

## 4. Главна функция main

Всяка Haskell програма, която иска да се изпълни, трябва да има функция `main` от тип `IO ()`. Това е входната точка на програмата.

### 4.1 Пример


## 5. Конструкция do

`do` нотацията е синтактична захар, която прави работата с IO операции по-четима. Тя позволява да пишем последователни IO операции по императивен начин.

### 5.1 Синтаксис

```haskell
main = do
  действие1 -- Индентацията е от значение
  действие2
  променлива <- действие3  -- Резултатът се присвоява на променлива
  действие4 променлива
```

### 5.2 Пример

```haskell
main :: IO ()
main = do
  putStr "Enter your name: "
  name <- getLine

  putStr "Enter your age: "
  ageLine <- getLine

  let age = read ageLine :: Int

  putStrLn ("Hey, " ++ name ++ "! Next year you would be " ++ show (age + 1) ++ " years old!")
```

## 6. Работа с файлове

За работа с файлове в Haskell използваме функции от модула `System.IO`.

### 6.1 Основни функции

```haskell
import System.IO

-- Отваряне на файлове
openFile :: FilePath -> IOMode -> IO Handle
data IOMode = ReadMode | WriteMode | AppendMode | ReadWriteMode -- видовете режим на работа

-- Затваряне на файл
hClose :: Handle -> IO ()

-- Четене от файл
hGetLine :: Handle -> IO String
hGetContents :: Handle -> IO String
readFile :: FilePath -> IO String  -- Удобна функция - отваря, чете и затваря

-- Писане във файл
hPutStr :: Handle -> String -> IO ()
hPutStrLn :: Handle -> String -> IO ()
hPrint :: Show a => Handle -> a -> IO ()
writeFile :: FilePath -> String -> IO ()  -- Удобна функция - отваря, пише и затваря
appendFile :: FilePath -> String -> IO () -- Удобна функция - отваря, добавя в края и затваря
```

### 6.2 Примери

```haskell
import System.IO

-- Пример 1: Четене на цял файл
main = do
  content <- readFile "input.txt"
  putStrLn content

-- Пример 2: Писане във файл
main = do
  writeFile "output.txt" "Hello, File!"
  putStrLn "File written successfully"

-- Пример 3: Четене и писане ред по ред
main = do
  rHandle <- openFile "input.txt" ReadMode
  line1 <- hGetLine rHandle
  line2 <- hGetLine rHandle
  hClose rHandle

  wHandle <- openFile "output.txt" WriteMode
  hPutStrLn wHandle line1
  hPutStrLn wHandle line2
  hClose wHandle
```
