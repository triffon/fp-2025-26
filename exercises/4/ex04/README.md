## 1. Наредени двойки (Pairs)

В Scheme основната структура за съхранение на данни е **наредената двойка** (pair). Тя се създава с функцията `cons`. Елементите й се достъпват с `car` и `cdr`.

### 1.1 Синтаксис и основни функции

```scheme
(cons 1 2)        ; Създава наредена двойка (1 . 2)
(car (cons 1 2))  ; => 1 (първият елемент)
(cdr (cons 1 2))  ; => 2 (вторият елемент)
```

**Важно:** `cons` създава **неизменяема** структура. Веднъж създадена, двойката не може да се променя.

### 1.2 Вложени двойки

Двойките могат да се влагат една в друга, което позволява създаването на сложни структури:

```scheme
(cons 1 (cons 2 3))  ; => (1 . (2 . 3))
(car (cons 1 (cons 2 3)))  ; => 1
(car (cdr (cons 1 (cons 2 3))))  ; => 2
```

## 2. Списъци (Lists)

Списъкът в Scheme е специален случай на наредени двойки. Той е рекурсивна структура, където:

- Празният списък `'()` е базовият случай
- Непразният списък е двойка от елемент (глава) и друг списък (опашка)

### 2.1 Създаване на списъци

```scheme
'()                    ; Празен списък
(cons 1 '())           ; Списък с един елемент: (1)
(cons 1 (cons 2 '()))  ; Списък с два елемента: (1 2)
(cons 1 (cons 2 (cons 3 '())))  ; Списък с три елемента: (1 2 3)
(list 1 2 3)           ; Същото като горното, но по-удобно
```

### 2.2 Основни функции за работа със списъци

```scheme
(car '(1 2 3 4 5))       ; => 1 (първият елемент)
(cdr '(1 2 3 4 5))       ; => (2 3 4 5) (останалата част)
(cadr '(1 2 3 4 5))      ; => 2 (вторият елемент)
(caddr '(1 2 3 4 5))     ; => 3 (третият елемент)
(cadddr '(1 2 3 4 5))    ; => 4 (четвъртият елемент)
(caddddr '(1 2 3 4 5))   ; => caddddr: unbound identifier (имаме дефинирани функции само до 4тият елемент)
(null? '())        ; => #t (проверка за празен списък)
(null? '(1 2))     ; => #f
```

## 3. Функции от по-висок ред над списъци

Функциите от по-висок ред са мощни инструменти за работа със списъци. Те позволяват да се абстрахираме от конкретните операции и да се фокусираме върху структурата на данните.

### 3.1 Вградени функции

На лекции вече сте разглеждали имплементации на някои класическите функции от по-висок ред за работа със списъци. Racket предоставя повечето от тях в стандартната си библиотека. Ето основните:

```scheme
; Map - прилага функция върху всеки елемент
(map square '(1 2 3 4))  ; => (1 4 9 16)
(map (lambda (x) (* x 3)) '(1 2 3))  ; => (3 6 9)

; Filter - филтрира елементи по предикат
(filter even? '(1 2 3 4 5 6))  ; => (2 4 6)
(filter (lambda (x) (> x 3)) '(1 2 3 4 5))  ; => (4 5)

; Foldr - натрупва стойности отдясно наляво
(foldr + 0 '(1 2 3 4))  ; => 10
(foldr - 1 '(1 2 3 4))  ; => -1

; Foldl - натрупва стойности отляво надясно
(foldl + 0 '(1 2 3 4))  ; => 10
(foldl - 0 '(1 2 3 4))  ; => 2  (за разлика от foldr)

; Andmap - проверява дали всички елементи удовлетворяват предиката
(andmap even? '(2 4 6))  ; => #t
(andmap even? '(2 4 5))  ; => #f

; Ormap - проверява дали поне един елемент удовлетворява предиката
(ormap odd? '(2 4 6))  ; => #f
(ormap odd? '(2 4 5))  ; => #t

; Apply - прилага функция върху списък от аргументи
(apply + '(1 2 3 4))  ; => 10 (еквивалентно на (+ 1 2 3 4))
(apply max '(5 2 8 1))  ; => 8 (еквивалентно на (max 5 2 8 1))
(apply list '(a b c))  ; => (a b c) (еквивалентно на (list a b c))
(apply cons '(1 '(2 3)))  ; => (1 2 3) (еквивалентно на (cons 1 '(2 3)))
```

**Важно:** `foldl` в Racket е имплементиран по различен начин от това, което е показвано на лекции. Вижте сравнението в слайдовете.

## 4. Видове сравняване за равенство

В Scheme има три основни функции за сравняване на равенство, всяка с различно поведение:

Ако имаме следните дефиниции:

```scheme
(define a (expt 2 100))   ; важно е, че 2^100 вече се представя в паметта като `Bignum`
(define b (expt 2 100))   ; същата оценка като a, но сметната отделно

(define tuple (cons 1 2)) ; наредена двойка
```

### 4.1 `eq?` - сравняване по идентичност

```scheme
(define test 1)
(eq? 1 1)           ; => #t (едни и същи литерали)
(eq? 1 test)           ; => #t (едни и същи литерали)

(eq? a b) ; #f (различни оценки в паметта)

(eq? (cons 1 2) (cons 1 2))  ; => #f (различни обекти в паметта)
(eq? tuple tuple)  ; => #t (еднакви обекти в паметта)
```

`eq?` проверява дали двата обекта са **едно и също** в паметта или оценките им са конкретни _прости_ литерали.

### 4.2 `eqv?` - сравняване по еквивалентност

```scheme
(eqv? a b) ; #t (еднакви стойности)

(eqv? (cons 1 2) (cons 1 2))  ; => #f (различни сложни обекти/структури)

(eqv? tuple tuple)  ; => #t (еднакви обекти в паметта)
```

`eqv?` проверява еквивалентност на стойности (под стойности разбираме числа, символи, булеви).
_Бележка:_ Ако `eq?` връща `#t` за два израза, то и `eqv?` ще връща `#t` за тях.

### 4.3 `equal?` - структурно сравняване

```scheme
(equal? a b) ; #t (еднакви стойности)

(equal? (cons 1 2) (cons 1 2))  ; => #t (еднакви стойности в сложни обекти/структури)
```

`equal?` прави **структурно сравняване** - проверява дали структурите са еднакви (тоест проверява и за наредени двойки)
_Бележка:_ Ако `eqv?` връща `#t` за два израза, то и `equal?` ще връща `#t` за тях.
