# Упражнение 3: Функции от по-висок ред. Анонимни функции

## 1. Функции от по-висок ред (Higher-Order Functions)

Във функционалното програмиране функциите са _първокласни обекти_. Това означава, че функциите могат да бъдат:

- **Подадени като аргументи** на други функции
- **Върнати като резултат** от функции
- **Съхранени в променливи**

Функция, която приема друга функция като аргумент или връща функция като резултат, се нарича **функция от по-висок ред**.

### 1.1 Функции като аргументи

**Пример - прилагане на функция два пъти:**

```scheme
(define (apply-twice f x)
  (f (f x)))

(define (add-one x)
  (+ x 1))

(apply-twice add-one 5)  ; => 7
```

### 1.2 Функции като резултат

**Пример - създаване на функция, която събира число с друго фиксирано число:**

```scheme
(define (add-x x)
  (define (result-fn y)
    (+ x y))
  result-fn) ; Резултатът от извикването на add-x е функция

((add-x 3) 7) ; => 10 Можем да извикваме тази ф-ция със съответните и аргументи

(define add-3 (add-x 3)) ; Можем също да присвоим тази функция на нов символ (add-3)

; add-3 е функция като всяка друга и можем да си я извикваме
(add-3 2) ; => 5
(add-3 5) ; => 8
```

## 2. Анонимни функции (Lambda)

Понякога не искаме да даваме име на функция, особено ако я използваме само веднъж. За това служат **анонимните функции** (lambda функции).

### 2.1 Синтаксис

```scheme
(lambda (параметри)
  (тяло))
```

**Пример:**

```scheme
; Вместо да дефинираме:
(define (square x) (* x x))

; Можем да използваме lambda директно:
((lambda (x) (* x x)) 5)  ; => 25

; Или да я съхраним в променлива:
(define square (lambda (x) (* x x)))
```

### 2.2 Използване с функции от по-висок ред

Ламбда функциите са изключително удобни за употреба при функции от по-висок ред. Те могат да се използват както за параметри, така и за резултат.

**Пример:**

```scheme
; Използвайки дефиницията от по-горе за apply-twice, можем да не дефинираме add-one.
(apply-twice (lambda (x) (+ 1 x)) 5)  ; => 7

; А горната имплементация на add-x, може да се сведе до следното използвайки `lambda`
(define (add-x x)
  (lambda (y) (+ x y)))
```

## 3. Задачи ✍️

**Задача 1:** Напишете функция `apply-n-times`, която приема функция `f`, число `n` и стартова стойност `x`, и прилага функцията `f` върху `x` общо `n` пъти. Например:

```scheme
(apply-n-times add-3 3 5)  ; => 14
(apply-n-times square 2 2)   ; => 16 (защото ((2^2)^2) = 16)
```

**Допълнение:** Използвайте `apply-n-times` с подадена lambda ф-ция, за да намерите резултата от `((5 + 3) * 2) * 2`. **НЕ** използвайте дефиниции на помощни функции.

_Подсказка:_ Функцията `apply-n-times` трябва да приложи операцията "умножи по 2" два пъти върху началната стойност `(5 + 3)`.

**Задача 2:** Напишете функция `compose`, която приема две функции `f` и `g` и връща функция, която прилага първо `g`, а после `f` върху даден аргумент. Тоест `(compose f g)` трябва да върне функция, която прави `f(g(x))`.

```scheme
(define square-plus-3 (compose add-3 square)) ; Смята x^2 + 3
(square-plus-3 5)  ; => 28
```

**Допълнение:** Използвайте lambda функции и `compose`, за да създадете функция, която приема число `x` и връща `(x + 1)^2`. Приложете я върху числото 4.

**Задача 3:** Напишете ф-ция `partial-apply` за частично прилагане (partial application) на аргументи. Функцията трябва да:

1. Приема първи аргумент функция `f`, която е функция, която работи с 2 аргумента
2. Приема втори аргумент `x`, който ще е първият аргумент на ф-цията `f`
3. Връща като резултат нова функция, този път такава, която приема само един аргумент `y` и при извикването си прилага първоначалната ф-ция `f` с първи аргумент `x` и втори аргумент `y`

Пример:

```scheme
(define add-5 (partial-apply + 5)) ; add-5 е ф-ция с 1 аргумент, която ще прилага оператора + над фиксирания аргумент 5 и новия аргумент
(add-5 7)  ; => 12 - свежда се до (+ 5 7)

(define multiply-by-2 (partial-apply * 2))
(multiply-by-2 4)  ; => 8
```

## 4. Функции от по-висок ред и работа с интервали

Можем да дефинираме функция (като от лекции), която натрупва ("акумулира") стойности върху затворен интервал `[a, b]` от естествени числа:

```scheme
(define (accumulate-interval combiner null-value a b)
  (if (> a b)
      null-value
      (combiner a
                (accumulate-interval combiner null-value (+ a 1) b))))
```

Тази функция приема:

- `combiner` - бинарна функция за комбиниране на стойности (например `+` или `*`)
- `null-value` - началната/неутрална стойност (например `0` за `+`, `1` за `*`)
- `a` и `b` - начало и край на интервала

**Пример - сума от 1 до 10:**

```scheme
(accumulate-interval + 0 1 10)  ; => 55
```

### Задачи за акумулиране върху интервали ✍️

**Задача 4.1:** Обогатете `accumulate-interval` така, че да приема и допълнителна функция `term` (отново като на лекция, но го направете вие вместо да я копирате), която да се прилага над всеки елемент от интервала **преди** да бъде използван от **combiner**

**Пример за употреба - сума на квадратите от 1 до 5:**

```scheme

```

**Задача 4.2:** Използвайте новия `accumulate-interval`, за да напишете функция `product-interval`, която приема две числа `a` и `b` и връща произведението на всички числа в интервала `[a, b]`.


**Задача 4.3:** Използвайте новия `accumulate-interval`, за да напишете функция `sum-odd-squares`, която приема две числа `a` и `b` и връща сумата на квадратите на нечетните числа в интервала `[a, b]`.

## 4. Предикати и функции от по-висок ред

Функциите от по-висок ред често работят с предикати (функции, които връщат `#t` или `#f`). Натрупването (accumulate) на булеви стойности всъщност е по-просто от това на "случайни" стойности. Има и други начини за акумулиране на булеви стойности, но двата основни вида операции за натрупване са "и" (`and`) и "или" (`or`). Нека да имплементираме функции от по-висок ред, които да ги прилагат:

### Задачи за предикати ✍️

**Задача 4.1:** Напишете функция `every?`, която приема предикат `p` и две числа - `a` и `b`. Функцията да проверява дали предиката е истина за всички числа в интервала [a, b].

```scheme
(every? even? 2 10)  ; => #f (защото 3,5,7,9 са нечетни)
(every? positive? 1 10)  ; => #t (защото всички са положителни)
```

**Задача 4.2:** Напишете функция `some?`, която приема предикат `p` и две числа - `a` и `b`. Функцията да проверява дали предиката е истина за поне едно число в интервала [a, b].

```scheme
(some? even? 1 5)  ; => #t (защото 2 и 4 са четни)
(some? (lambda (x) (> x 100)) 1 10)  ; => #f
```

**Задача 4.3:** Напишете функция `all-divisors?`, която приема три числа: `n`, `a` и `b`, и проверява дали всички числа в интервала `[a, b]` са делители на `n`.

```scheme
(all-divisors? 12 1 3)   ; => #t (1,2,3 делят 12)
(all-divisors? 12 1 5)   ; => #f (5 не дели 12)
```

**Задача 4.4:** Напишете функция `some-negative?`, която приема две числа: `a` и `b`, и проверява дали поне едно от числата в интервала `[a, b]` са отрицателни.

```scheme
(some-negative? 0 3)   ; => #f (всички са неотрицателни)
(some-negative? -2 5)   ; => #f (-2 и -1 са отрицателни)
```
