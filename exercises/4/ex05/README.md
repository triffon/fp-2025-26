# Упражнение 5: Асоциативни списъци. Дървета

## 1. Асоциативни списъци (Association Lists)

Асоциативните списъци са списъци от наредени двойки, които се използват за съхранение на връзки тип "ключ-стойност". На практика те не са нищо по различно от списък от наредени двойки. Първият елемент на всеки от вложените списъци наричаме ключ. Вторият му наричаме стойност.

### 1.1 Синтаксис и основни функции

```scheme
; Създаване на асоциативен списък
(define phone-book
  '((alice . "555-1234")
    (bob . "555-5678")
    (charlie . "555-9012")))

; Основни функции за работа с асоциативни списъци
(assoc 'alice phone-book)     ; => (alice . "555-1234")
(assq 'bob phone-book)        ; => (bob . "555-5678") - използва eq? за сравнение
(assv 42 '((1 . "one") (42 . "forty-two"))) ; => (42 . "forty-two") - използва eqv?
```

**Важно:** `assoc`, `assq` и `assv` връщат цялата двойка, а не само стойността. За да получите стойността, използвайте `cdr`.

### Задачи за асоциативни списъци ✍️

**Задача 1.1:** Напишете функция `add-entry`, която приема ключ, стойност и асоциативен списък и връща нов списък с добавената двойка в началото.

```scheme
(add-entry 'david "555-3456" phone-book)  ; => ((david . "555-3456") (alice . "555-1234") ...)
```

**Задача 1.2:** Напишете функция `remove-entry`, която приема ключ и асоциативен списък и връща нов списък без двойката с този ключ.

```scheme
(remove-entry 'bob phone-book)  ; => ((alice . "555-1234") (charlie . "555-9012"))
```

**Задача 1.3:** Напишете функция `update-entry`, която приема ключ, нова стойност и асоциативен списък. Ако ключът съществува, функцията да връща нов списък с обновената стойност. Ако не съществува, да добави новата двойка.

```scheme
(update-entry 'alice "555-9999" phone-book)  ; => ((alice . "555-9999") (bob . "555-5678") ...)
```

## 2. Дървета (Trees)

Дърветата са рекурсивни структури от данни, състоящи се от възли (nodes) и ребра (edges). В Scheme дърветата се представят като списъци, където първият елемент е стойността на възела, а останалите са поддърветата.

### 2.1 Представяне на дървета

```scheme
; Дърво (tree) - първият елемент е стойността, останалите са децата
(define simple-tree
  '(1
    (2 (4) (5))
    (3 (6) (7))
    (8)))
```

### 2.2 Основни функции за работа с дървета

```scheme
; Функции за достъп до елементите на дърво
(define (tree-value tree) (car tree)) ;
(define (tree-children tree) (cdr tree))

; Проверка за листо (възел без деца)
(define (leaf? tree) (null? (tree-children tree)))
```

### Задачи за дървета ✍️

**Задача 2.1:** Напишете функция `tree-size`, която приема дърво и връща броя на възлите в него.

```scheme
(tree-size simple-tree)  ; => 8
(tree-size '(1))         ; => 1
```

**Задача 2.2:** Напишете функция `tree-height`, която приема дърво и връща височината му (броя нива).

```scheme
(tree-height simple-tree)  ; => 3
(tree-height '(1))         ; => 1
```

**Задача 2.3:** Напишете функция `tree-leaves`, която приема дърво и връща списък от всички листа.

```scheme
(tree-leaves simple-tree)  ; => (4 5 6 7 8)
```

**Задача 2.4:** Напишете функция `tree-sum`, която приема дърво от числа и връща сумата на всички стойности в дървото.

```scheme
(tree-sum simple-tree)  ; => 36 (1+2+3+4+5+6+7+8)
```

**Задача 2.5:** Напишете функция `tree-map`, която приема функция и дърво и връща ново дърво с приложената функция върху всяка стойност.

```scheme
(tree-map (lambda (x) (* x 2)) simple-tree)  ; => (2 (4 (8) (10)) (6 (12) (14)) (16))
```

**Задача 2.6:** Напишете функция `tree-find`, която приема предикат и дърво и връща първата стойност, която удовлетворява предиката, или `#f` ако няма такава.

```scheme
(tree-find even? simple-tree)  ; => 2
(tree-find (lambda (x) (> x 10)) simple-tree)  ; => #f
```

## 3. Комбинирани задачи

**Задача 3.1:** Напишете функция `tree-balance`, която приема дърво и проверява дали е балансирано (разликата във височините на поддърветата на всяко ниво е най-много 1).

```scheme
(displayln (tree-balance simple-tree)) ; #t
(displayln (tree-balance '(1 (2) (3))))  ; #t
(displayln (tree-balance '(1 (2 (4)) (3)))) ; #t
(displayln (tree-balance '(1 (2 (4 (5))) (3)))) ; #f
```

**Задача 3.2:** Напишете функция `count-occurances`, която приема списък от числа, и връща асоциативен списък, където ключовете са уникалните числа от списъка, а стойностите са броят на срещанията им.

```scheme
(count-occurances '(1 2 2 3 3 3 4))  ; => ((4 . 1) (3 . 3) (2 . 2) (1 . 1))
(count-occurances '(5 5 5 5))  ; => ((5 . 4))
(count-occurances '(1 2 3))  ; => ((3 . 1) (2 . 1) (1 . 1))
```
