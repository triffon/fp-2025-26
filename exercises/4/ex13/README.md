## 1. Собствени списъци

Миналия път видяхме как можем да дефинираме собствен списък. Нека разгледаме тази структура отново и да дефинираме функцията `listMap`.

```haskell
data List a = Empty
            | Cons a (List a)
            deriving (Show)

-- Пример: списъкът [1, 2, 3]
-- Cons 1 (Cons 2 (Cons 3 Empty))
```

### Реализация на `listMap`

Често искаме да трансформираме всички елементи на списъка с дадена функция.

```haskell
listMap :: (a -> b) -> List a -> List b
listMap _ Empty = Empty
listMap f (Cons x xs) = Cons (f x) (listMap f xs)

-- Употреба:
-- listMap (+1) (Cons 1 (Cons 2 Empty))
-- -> Cons 2 (Cons 3 Empty)
```

## 2. Класът Functor

Не би ли било приятно обаче, ако можехме да дефинираме някаква "обща" функция за map-ване, която да работи за всякакви структури - списъци, List, дървета... Ами всъщност в Haskell съществува клас, който обобщава идеята за "структура, чиито елементи могат да се трансформират" (mapping). Този клас се нарича `Functor`.

```haskell
class Functor f where
    fmap :: (a -> b) -> f a -> f b
    (<$) :: a -> f b -> f a  -- Заменя всички стойности с една константа
```

Вместо да пишем `listMap`, `treeMap`, `maybeMap`, ние дефинираме как нашата структура се държи като `Functor` чрез инстанцирането му.

### Инстанция за List

```haskell
instance Functor List where
    fmap _ Empty = Empty
    fmap f (Cons x xs) = Cons (f x) (fmap f xs)
```

Сега можем да ползваме `fmap` (или оператора `<$`) за нашите списъци, както и за вградените типове (`[]`, `Maybe`, `IO` и др.).

## 4. Задачи за двоични наредени дървета за търсене (BST) ✍️

Двоично дърво за търсене (BST) е дърво, за което е в сила свойството:

> За всеки възел, всички елементи в **лявото** поддърво са **по-малки** от него, а всички в **дясното** са **по-големи** (или равни).

**Задача 4.1:** Реализирайте функция `bstInsert :: Ord a => a -> Tree a -> Tree a` - вмъква елемент, запазвайки наредбата.

```haskell
-- bstInsert 4 t
-- Резултат:
--      5
--     / \
--    3   7
--     \
--      4
```

**Задача 4.2:** Реализирайте функция `bstSearch :: Ord a => a -> Tree a -> Bool` - търси елемент (_оптимизирано_).

```haskell
-- bstSearch 3 t -> True
-- bstSearch 9 t -> False
```

**Задача 4.3:** Реализирайте функция `bstValues :: Tree a -> [a]` - обхожда дървото (Ляво-Корен-Дясно) и връща списък с елементите. _Резултатът трябва да е сортиран списък._

```haskell
-- bstValues t -> [3, 5, 7]
-- bstValues (bstInsert 4 t) -> [3, 4, 5, 7]
```

**Задача 4.4:** Реализирайте функция `isSymmetric :: Tree a -> Bool` - проверява дали структурата на дървото е огледална спрямо корена.

```haskell
--      3
--     / \
--    2   3
--   /     \
--  1       5
-- isSymmetric symTree -> True
```
