## 1. Основни типове

Haskell е строго типизиран език с автоматично извеждане на типове. Основните типове включват:

- `Int` - цели числа с фиксирана точност
- `Integer` - цели числа с произволна точност
- `Float` и `Double` - числа с плаваща запетая
- `Bool` - булеви стойности (`True`, `False`)
- `Char` - единичен символ
- `String` - низ (всъщност е `[Char]`)

**Пример за типове:**

```haskell
-- Числа
42 :: Int
3.14 :: Double

-- Булеви стойности
True :: Bool
False :: Bool

-- Символи и низове
'a' :: Char
"Hello" :: String
```

## 2. Дефиниране и извикване на функции

В Haskell функциите се дефинират с помощта на знака `=`. Синтаксисът е:

```haskell
име-на-функция :: Тип-на-арг1 -> Тип-на-арг2 -> ... -> Тип-на-резултат
име-на-функция арг1 арг2 ... = израз
```

**Пример - функция за намиране на квадрат:**

```haskell
-- В случая Хаскел може сам да се досети за типа на функцията
-- и без да му я казваме
square :: Int -> Int
square x = x * x

-- Извикване:
square 5  -- => 25
```

**Пример - функция с два аргумента:**

```haskell
add :: Int -> Int -> Int
add x y = x + y

-- Извикване:
add 3 5  -- => 8
```

**Важно:** В Haskell НЯМА скоби около аргументите при извикване на функции. `f(x, y)` е грешно, правилното е `f x y`.

## 3. Currying и частично прилагане

В Haskell всички функции са **curried** - това означава, че функция с `n` аргумента всъщност е функция, която приема един аргумент и връща нова функция, която приема `n - 1` аргумента и т.н.

**Пример:**

```haskell
add 3 -- => функция от тип Int -> Int
add 3 5 -- => 8 (число от тип Int)
```

**Частично прилагане** е техника, при която подаваме по-малко аргументи отколкото функцията очаква, получавайки като резултат нова функция.

**Пример:**

```haskell
-- Частично прилагане
add3 :: Int -> Int
add3 = add 3

add3 5  -- => 8 (еквивалентно на add 3 5)
```

### Оператори и функции

В Haskell операторите (като `+`, `-`, `*`, `/`, `==`, `>`, `<` и др.) са всъщност функции, но се използват в **инфиксна нотация** (между аргументите). Обикновените функции се използват в **префиксна нотация** (преди аргументите).

**Разлика между оператор и функция:**

```haskell
-- Оператор в инфиксна нотация
3 + 5  -- => 8

-- Функция в префиксна нотация
add 3 5  -- => 8 (еквивалентно на 3 + 5)
```

**Конвертиране между оператор и функция:**

1. **От оператор към функция:** Ограждаме оператора в скоби `()`

   ```haskell
   (+) :: Int -> Int -> Int
   (-) :: Int -> Int -> Int
   (*) :: Int -> Int -> Int
   (==) :: Int -> Int -> Bool
   ```

2. **От функция към оператор:** Ограждаме името на функцията в обратни кавички `` ` ``

   ```haskell
   -- Обикновена функция
   add x y = x + y

   -- Използване като оператор
   3 `add` 5  -- => 8 (еквивалентно на add 3 5)
   ```

## 4. Локални дефиниции - let и where

Понякога искаме да дефинираме помощни стойности или функции, които се използват само в рамките на друга функция. За това служат `let` и `where`.

### 4.1 let изрази

`let` изразите позволяват локални дефиниции в рамките на израз:

```haskell
функция аргументи =
  let локална-дефиниция1 = стойност1
      локална-дефиниция2 = стойност2
  in израз-използващ-локалните-дефиниции
```

**Пример:**

```haskell
hypotenuse :: Double -> Double -> Double
hypotenuse a b =
  let aSquared = a * a
      bSquared = b * b
  in sqrt (aSquared + bSquared)
```

### 4.2 where клаузи

`where` клаузите са алтернативен начин за локални дефиниции, но те се поставят в края на функцията:

```haskell
функция аргументи = израз
  where локална-дефиниция1 = стойност1
        локална-дефиниция2 = стойност2
```

**Пример:**

```haskell
hypotenuse :: Double -> Double -> Double
hypotenuse a b = sqrt (aSquared + bSquared)
  where aSquared = a * a
        bSquared = b * b
```

**Разлика между `let` и `where`:**

- `let` е израз и може да се използва навсякъде
- `where` е клауза и може да се използва само в дефиниции на функции

**Подсказка за [формулата](https://bg.wikipedia.org/wiki/%D0%A1%D0%BA%D0%B0%D0%BB%D0%B0%D1%80%D0%BD%D0%BE_%D0%BF%D1%80%D0%BE%D0%B8%D0%B7%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5):** Това е `<скаларното произведение на a и b> / (<дължината на a> * <дължината на b>)` => `(a1 * b1 + a2 * b2) / (sqrt(a1^2 + a2^2) * sqrt(b1^2 + b2^2))`


## 5. Функции с гардове (Guards)

Гардовете позволяват да проверяваме условия и да връщаме различни стойности в зависимост от тях. Синтаксисът е:

```haskell
функция аргументи
  | условие1 = стойност1
  | условие2 = стойност2
  | otherwise = стойност-по-подразбиране
```

**Пример - знак на число:**

```haskell
sign :: Int -> Int
sign x
  | x > 0 = 1
  | x < 0 = -1
  | otherwise = 0
```

## 6. Функции чрез последователност от равенства (Pattern Matching)

Pattern matching позволява да дефинираме функции чрез множество случаи, всеки от които съответства на различна структура на аргументите.

**Пример - факториел с pattern matching:**

```haskell
factorial :: Int -> Int
factorial 0 = 1
factorial n = n * factorial (n - 1)
```

**Важно:** Редът на случаите е важен! По-специфичните случаи трябва да са преди по-общите.
