# Двоични дървета и задачи за упражнение.

## Двоични дървета

Днес ще използваме имплементацията на двоично дърво от лекции, където всяко дърво е дефинирано по следния начин:

- Празният списък е дърво
- Дърво е също така всяка наредена тройка (списък с точно 3 елемента), където първият елемент е стойността на възела, вторият е лявото поддърво, а третият - дясното.

```scheme
(define (tree? t)
  (or (null? t)
      (and (list? t)
           (= (length t) 3)
           (tree? (cadr t))
           (tree? (caddr t))))) ; рекурсивната дефиниция представена като предикат

(define empty-tree '()) ; празното дърво е празен списък
(define (make-tree root left right) (list root left right)) ; конструктор за дърво с ляво и дясно поддърво
(define (make-leaf root) (make-tree root empty-tree empty-tree))  ; конструктор за листо
(define root-tree car) ; getter за стойността на възела
(define left-tree cadr) ; getter за лявото поддърво
(define right-tree caddr) ; getter за дясното поддърво
(define empty-tree? null?) ; предикат за проверка на празно поддърво
```

Примерно дърво:

```scheme

(define t (make-tree 5
                     (make-tree 1
                                (make-tree 4
                                           '()
                                           (make-leaf 13))
                                (make-leaf 3))
                     (make-tree 8
                                (make-tree 0
                                           (make-leaf 10)
                                           (make-leaf 9))
                                (make-leaf 11))))

```

### Задача 0

Можете да решите всяка една от задачите от [упражнение 5](../ex05/README.md#2-дървета-trees), но с ограничението за двоични дървете.

_Бележка:_ Ако ви затруднява факта, че сме работили с малко по-различна имплементация винаги можете да викнете `(cdr t)` или да си конструирате списък с `(list (left-tree t) (right-tree t))`, което отново би свело задачата до "списък от всички поддървета" (просто винаги ще са 2) и да решавате задачата аналогично с представянето от миналият път. ### Задача 1

Да се напише функция `traverse`, която приема двоично дърво `t` и обхожда дървото ляво-корен-дясно, връщайки списък от елементите на дървото.

```scheme
(traverse t) ; -> '(4 13 1 3 5 10 0 9 8 11)
```

### Задача 2

Да се напише функция `level`, която приема число `k` и двоично дърво `t`, която връща елементите на дървото на ниво `k`. Считаме, че коренът на дървото е на ниво 0.

```scheme
(level 1 t)  ; -> (1 8)
(level 2 t)  ; -> '(4 3 0 11)
(level 4 t2) ; -> '()
```

### Задача 3

Да се напише функция `list->bst`, която приема списък от числа и връща двоично сортирано дърво (BST - Binary Search Tree). Първият елемент от списъка става коренът на дървото, а всички останали елементи се вмъкват според правилото: по-малките от корена отиват вляво, по-големите или равните - вдясно.

```scheme
(list->bst '(5 2 8 1 3 7 9))  ; => '(5 (2 (1 () ()) (3 () ())) (8 (7 () ()) (9 () ())))
(list->bst '(10 5 15 3 7))    ; => '(10 (5 (3 () ()) (7 () ())) (15 () ()))
(list->bst '(1))               ; => '(1 () ())
(list->bst '())                ; => '()
```

### Задача 4

Да се напише функция `bst-search`, която приема число `x` и двоично сортирано дърво `t`, и връща `#t` ако числото се съдържа в дървото, и `#f` в противен случай.

```scheme
(define bst (list->bst '(5 2 8 1 3 7 9)))
(bst-search 3 bst)   ; => #t
(bst-search 7 bst)   ; => #t
(bst-search 10 bst)  ; => #f
(bst-search 0 bst)   ; => #f
```

## Задачи за упражнение

### Задача 1а: Разлика между число и неговото обърнато число

Напишете функция `diffReverse`, която приема естествено число `n` и връща разликата между числото и неговото обърнато число.

**Примери:**

```scheme
(diffReverse 7641)  ; => 7641 - 1467 = 6174
(diffReverse 123)   ; => 123 - 321 = -198
(diffReverse 7)     ; => 7 - 7 = 0
```

### Задача 1б: Сортиране на цифри в число

Напишете функция `sort-digits`, която приема естествено число `n` и връща ново число, чиито цифри са подредени в низходящ ред (от най-голямата към най-малката).

**Примери:**

```scheme
(sort-digits 6174)     ; => 7641
(sort-digits 9912939)  ; => 9999321
(sort-digits 0)        ; => 0
(sort-digits 123456789) ; => 987654321
```

### Задача 2: Пермутируеми функции

Напишете функция `permutable?`, която приема две числа `a` и `b` (където `a ≤ b`), и две функции `f` и `g`. Функцията проверява дали функциите `f` и `g` са пермутируеми за всички четни числа в интервала `[a, b]`.

Две функции `f` и `g` се наричат пермутируеми, ако за всяко число `x` е изпълнено: `f(g(x)) = g(f(x))`.

**Бележка:** Функцията трябва да проверява само четните числа в интервала `[a, b]`. Ако `a` е нечетно, започнете проверката от `a + 1`.

**Примери:**

```scheme
(permutable? 1 9 (lambda (x) (* x x)) (lambda (x) (* x x x))) ; => #t
(permutable? 1 9 (lambda (x) (+ x 1)) (lambda (x) (- x 2)))   ; => #t
(permutable? 1 9 (lambda (x) (* x x)) (lambda (x) (/ x 2)))   ; => #f
(permutable? 1 9 (lambda (x) (* x x)) (lambda (x) (+ 100 x))) ; => #f
```

### Задача 3: Подмножества на най-дългия интервал

Напишете функция `longest-interval-subset`, която приема списък от интервали (представени като наредени двойки `(a . b)`, където `a ≤ b`) и връща списък от всички интервали, които са подмножества на най-дългия интервал в списъка.

**Примери:**

```scheme
(define test '((24 . 25) (90 . 110) (0 . 100) (10 . 109) (1 . 3) (-4 . 2)))
(longest-interval-subset test)  ; => списък от интервали, които са подмножества на най-дългия
```

### Задача 4: Сортиране на списък от числа

Напишете функция `quick-sort`, която приема списък от числа и връща нов списък със същите числа, сортирани в нарастващ ред, използвайки алгоритъма за бързо сортиране (quicksort).

**Примери:**

```scheme
(quick-sort '(5 2 8 1 9 3))  ; => (1 2 3 5 8 9)
(quick-sort '(10 5 2 7))     ; => (2 5 7 10)
(quick-sort '(1))             ; => (1)
(quick-sort '())              ; => ()
(quick-sort '(5 5 2 5 2))     ; => (2 2 5 5 5)
```
