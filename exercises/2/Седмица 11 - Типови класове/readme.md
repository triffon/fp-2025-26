# Седмица 11 - Типови класове

## Задача 01 - Инстанции на типови класове
Напишете алгебричен тип данни `Temperature`, който представя температура, като градусите могат да са по Целзий или по Фаренхайт. За типа направете инстанции на следните вградени класове:

- `Show` - преобразува температура към символен низ, като записва стойността и след нея скалата, по която е била измерена (`°C` за Целзий и `°F` за Фаренхайт);
- `Eq` - проверява дали 2 температури са равни. Ако температурите са по различна скала, да се направи нужната трансформация, така че да могат да се сравнят;
- `Ord` - прави сравнение на 2 температури. Отново да се направи нужната трансформация, ако температурите са по различна скала. 

### Примери:
```hs
ghci> Celsius 24.5 -- 24.5°C
ghci> Fahrenheit 76.1 -- 76.1°F

ghci> (Celsius 24.5) == (Fahrenheit 76.1) -- True

ghci> (Celsius 24.5) > (Fahrenheit 24.5) -- True
ghci> (Celsius 100) < (Fahrenheit 200) -- False
```

### Забележка:
За следните класове може автоматично да бъде направена инстанция за всеки един алгебричен тип данни, посредством `deriving`: `Show, Read, Eq, Ord, Bounded, Enum`. В задачата се изисква да се направят ръчно инстанции, понеже описаното поведение не съвпада с поведението, което получаваме при автоматичните инстанции. 

## Задача 02 - Дефиниране на типови класове
Дефинирайте типов клас `Collectable`, обединяващ всички типове, чиито стойности могат да бъдат събрани в списък на база на даден предикат. Класът да съдържа следните функции:

- `collect :: (a -> Bool) -> c a -> [a]` - събира стойностите на `c`, които отговарят на подадения предикат, в списък;
- `collectAll :: c a -> [a]` - събира всички стойности на `c` в списък (конвертира `c` към списък);
- `find :: (a -> Bool) -> c a -> Maybe a` - търси елемент в `c`, който отговаря на подадения предикат;
- `forAll :: (a -> Bool) -> c a -> Bool` - проверява дали подаденият предикат е истина за всяка от стойностите в `c`.

При инстанцирането на класа `Collectable` да се даде имплементация само на `collect`. Всички останали функции да се имплементират в дефиницията на класа, използвайки `collect`.

Направете следните инстанции на `Collectable`:
- за списъци
- за типа `BinaryTree` от предния път
- за типовете `Maybe` и `Either` от предния път

### Примери:
```hs
ghci> collect (> 7) [3,8,5,4,9] -- [8,9]
ghci> find (== 5) [3,8,5,4,9] -- Just 5
ghci> find (== 2) [3,8,5,4,9] -- Nothing

ghci> collect (> 7) testTree -- [13,8,10,9,11]
ghci> collectAll testTree -- [5,1,4,13,3,8,0,10,9,11]
ghci> find (== 0) testTree -- Just 0
ghci> find (== 2) testTree -- Nothing
ghci> forAll (< 15) testTree -- True
ghci> forAll odd testTree -- False

ghci> collect (> 7) (Just 9) -- [9]
ghci> collect (> 7) (Just 2) -- []
ghci> collect (> 7) Nothing -- []
ghci> find (== 5) (Just 5) -- Just 5
ghci> find (== 5) (Just 3) -- Nothing
```

## Задача 04 - Класът Monoid
Напишете своя версия на вградения клас `Semigroup` и чрез нея напишете своя версия на вградения клас `Monoid`. `Semigroup` обединява всички типове, поддържащи асоциативна бинарна операция, а `Monoid` обединява всички типове, които инстанцират `Semigroup` и в допълнение имат неутрален елемент спрямо операцията. Направете следните инстанции на класа `Monoid`:

- за типа `Int` спрямо събирането
- за типа `Nat` от предния път относно събирането/умножението
- за типа `Maybe`, когато типовият аргумент е също `Monoid`
