## Задача 01 - От функтори, през апликативни функтори до монади
Разгледайте вградените класове `Functor`, `Applicative` и `Monad`. Направете инстанции на трите класове за вашите реализации на `Maybe` и `Either` от седмица 10. Ако сте направили правилно инстанциите за `Maybe`, трябва следният код да бъде валиден:

```hs
ghci> (^ 2) <$> (Just 5) -- Just 25
ghci> (^ 2) <$> Nothing -- Nothing

ghci> (Just (+ 3)) <*> (Just 7) -- Just 10
ghci> (Just (+ 3)) <*> Nothing -- Nothing
ghci> Nothing  <*> (Just 7) -- Nothing

ghci> (Just 3) >>= Just . (+ 5) . (* 2) -- Just 11
ghci> Nothing >>= Just . (+ 5) . (* 2) -- Nothing

safeDiv :: Double -> Double -> Maybe Double
safeDiv _ 0 = Nothing
safeDiv a b = Just $ a / b

composeMaybe :: Double -> Maybe Double
composeMaybe d = do
  let x = 100
  y <- safeDiv x 5
  z <- safeDiv y d
  safeDiv z 8

ghci> composeMaybe 4 -- Just 0.625
ghci> composeMaybe 0 -- Nothing
```

## Задача 02 - Монадата State
Дефинирайте алгебричен тип `State`, който съдържа една единствена стойност - функция `runState`, която приема тип `s` представляващ текущо състояние, и връщаща наредена двойка от тип `(a, s)`, където първата компонента е резултатът от прилагането на функцията върху текущото състояние, а втората компонента е новото състояние, което се получава след прилагането на функцията. Направете инстанция на класа `Monad` за този тип.

Напишете следните функции за работа със `State`:

- `get :: State s s` - връща `State`, който при изпълнение връща вътрешното си състояние
- `put :: s -> State s ()` - приема състояние и връща `State`, чието вътрешно състояние е равно на подаденото
- `modify :: (s -> s) -> State s ()` - приема функция, която трансформира състояние и връща `State`, който при изпълнение прилага функцията върху вътрешното си състояние

Използвайки `State`, направете симулация на банкови транзакции. Напишете следните функции:

- `deposit :: Int -> State Int ()` - депозира (добавя) пари към банкова сметка
- `withdraw :: Int -> State Int Bool` - опитва да изтегли пари от банкова сметка. Ако транзакцията е успешна, резултатът е `True` и сметката намалява с подадения брой пари, иначе резултатът е `False` и сметката остава непроменена

Ако сте реализирали правилно функциите, трябва следният код да се компилира успешно и да връща резултат `(True, 120)`:

```hs
session :: State Int String
session = do
  deposit 100
  ok1 <- withdraw 30
  deposit 50
  ok2 <- withdraw 150
  deposit 80
  return $ "Withdraw 30: " ++ show ok1 ++ "Withdraw 150: " ++ show ok2

ghci> runState session 0 -- ("Withdraw 30: TrueWithdraw 150: False",200)
```
